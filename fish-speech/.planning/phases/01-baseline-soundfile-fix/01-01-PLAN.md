```python
def load_audio(self, reference_audio: bytes | str, sr: int):
    """
    Load the audio data from a file or bytes.
    Uses soundfile instead of torchaudio to avoid torchcodec dependency.
    """
    if isinstance(reference_audio, bytes):
        reference_audio = io.BytesIO(reference_audio)

    waveform, original_sr = sf.read(reference_audio, dtype="float32")

    # Convert to mono if multi-channel
    if waveform.ndim > 1:
        waveform = waveform.mean(axis=1)

    # Resample if needed
    if original_sr != sr:
        import resampy
        waveform = resampy.resample(waveform, original_sr, sr)

    return waveform
```

Key differences from original:
- Uses `sf.read` (returns numpy array directly, no torch tensor wrapping needed)
- Uses `resampy.resample` instead of `torchaudio.transforms.Resample` (resampy is already a fish-speech dependency per pyproject.toml)
- Handles bytes input via isinstance check instead of the len > 255 heuristic
- Returns numpy array directly (same as original after .squeeze().numpy())
- dtype="float32" matches what the downstream DAC encoder expects

Do NOT modify any other methods in the file. The `__init__`, `load_by_id`, `load_by_hash`, etc. do not use torchaudio directly (they call `encode_reference` and `audio_to_bytes` from utils).
