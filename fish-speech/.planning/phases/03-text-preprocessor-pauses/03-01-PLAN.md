    ## Dataclasses (PAUS-05, per D-09/D-10/D-11)
    - PreprocessorConfig() defaults: enable_clause_injection=True, clause_word_threshold=8, enable_slow_tags=True, enable_pause_hints=True, pause_jitter_pct=0.175, enable_breathing_cues=True
    - HumanismHints has fields: pause_hints (list[PauseHint]), rate_hints (list[RateHint]), breathing_cues (list[BreathingCue]), original_text (str)
    - PauseHint has: char_offset (int), duration_ms (float), source (str)
    - RateHint has: char_offset (int), scope (str)
    - BreathingCue has: char_offset (int), probability (float)

    ## preprocess() returns tuple (per D-10)
    - preprocess("") returns ("", HumanismHints with empty lists)
    - preprocess("Hello.") returns ("Hello.", hints with original_text="Hello.")
    - preprocess(text) always returns (str, HumanismHints) tuple

    ## Clause boundary injection (PAUS-01, per D-01/D-02/D-03)
    - "She walked to the store and bought some milk and bread and cheese" -> comma injected before "and" (8+ words, coordinating conjunction)
    - "Hello world." -> no change (< 8 words)
    - "She said, hello world." -> no change (already has comma)
    - "I went to the store, bought milk, and came home." -> no change (already punctuated)
    - "The old man walked slowly through the park because he enjoyed the scenery" -> comma before "because" (subordinating conjunction, 8+ words before it)
    - Only one comma injected per long span (no multi-injection)
    - "[angry] She ran fast and far" -> no comma inside [angry] brackets
    - "He went to Dr. Smith and they talked for hours and then left" -> comma injected, abbreviation period not treated as sentence end

    ## Double-punctuation cleanup (anti-pattern from RESEARCH.md Pitfall 2)
    - After injection, no ",." or ",," or ", ;" patterns remain

    ## [slow] tag insertion (PAUS-04, per D-07/D-08)
    - "[angry] You betrayed me." -> "[slow] [angry] You betrayed me." ([slow] before sentence with emotion tag)
    - "Hello world." -> "Hello world." (no emotion tag, no [slow])
    - "[angry] Stop! [sad] I'm sorry." -> "[slow] [angry] Stop! [slow] [sad] I'm sorry." ([slow] before each emotion-tagged sentence)
    - "[slow] [angry] Already tagged." -> "[slow] [angry] Already tagged." (no double [slow])

    ## Pause hint generation (PAUS-02/PAUS-03, per D-04/D-05/D-06)
    - Pause hints generated at punctuation positions (commas, periods, semicolons, colons, em-dashes)
    - Each PauseHint has duration_ms with Gaussian jitter applied
    - Base durations: comma=150ms, semicolon=250ms, period=350ms, colon=200ms, em_dash=200ms
    - Jitter clamps to [0.5x, 1.5x] base duration
    - PauseHint.source is one of: "comma", "semicolon", "period", "colon", "em_dash", "sentence_boundary"

    ## Breathing cue generation (for Phase 4, per D-09)
    - BreathingCue placed before phrases of 15+ words
    - BreathingCue.probability is 0.0-1.0 (not always 1.0 -- sparse)
    - Short text (< 15 words total) produces no breathing cues

    ## Feature toggles
    - PreprocessorConfig(enable_clause_injection=False) -> no commas injected
    - PreprocessorConfig(enable_slow_tags=False) -> no [slow] tags inserted
    - PreprocessorConfig(enable_pause_hints=False) -> hints.pause_hints is empty list
    - PreprocessorConfig(enable_breathing_cues=False) -> hints.breathing_cues is empty list

  <implementation>
    Create `fish_speech/utils/text_preprocessor.py` following Phase 2's post_fx.py pattern:

    **Module-level compiled regex patterns:**
    - `_COORD_CONJ = re.compile(r'(?<=\s)(and|but|or|nor|yet|so|for)\s', re.IGNORECASE)` -- coordinating conjunctions (FANBOYS)
    - `_SUBORD_CONJ = re.compile(r'(?<=\s)(which|because|although|while|whereas|since|unless|until|though|where|when|if|after|before)\s', re.IGNORECASE)` -- subordinating conjunctions
    - `_LONG_UNPUNCTUATED = re.compile(r'(?<=[.!?,;:\s]|^)([^.!?,;:]{40,}?)(?=[.!?,;:]|$)')` -- spans of 40+ chars without punctuation (word count checked inside callback)
    - `_EMOTION_TAG = re.compile(r'\[([a-zA-Z]{2,12})\]\s*')` -- redefine locally (same pattern as inference.py) to avoid circular import
    - `_DOUBLE_PUNCT = re.compile(r',\s*([,;:.!?])')` -- cleanup pattern for double punctuation after injection
    - `_PUNCT_POSITIONS = re.compile(r'[,;:.!?\u2014]|(?:--)')` -- for finding punctuation positions for pause hints
    - `_SENTENCE_BOUNDARY = re.compile(r'(?<=[.!?])\s+')` -- for splitting into sentences for [slow] tag and breathing cue logic

    **Pause duration constants:**
    ```python
    _PAUSE_DURATIONS = {
        ',': 150, ';': 250, '.': 350, ':': 200,
        '!': 350, '?': 350, '\u2014': 200, '--': 200,
    }
    _PAUSE_SOURCE = {
        ',': 'comma', ';': 'semicolon', '.': 'period', ':': 'colon',
        '!': 'period', '?': 'period', '\u2014': 'em_dash', '--': 'em_dash',
    }
    ```

    **Dataclasses** (all using `from dataclasses import dataclass, field`):
    - `PreprocessorConfig` with 6 fields as specified in behavior
    - `PauseHint(char_offset: int, duration_ms: float, source: str)`
    - `RateHint(char_offset: int, scope: str)`
    - `BreathingCue(char_offset: int, probability: float)`
    - `HumanismHints(pause_hints, rate_hints, breathing_cues, original_text)` with `field(default_factory=list)` for lists

    **TextPreprocessor class:**
    - `__init__(self, config: PreprocessorConfig | None = None)` -- stores config, defaults to PreprocessorConfig()
    - `preprocess(self, text: str) -> tuple[str, HumanismHints]` -- main entry point. Steps: strip, early return on empty, inject clause commas, insert [slow] tags, generate pause hints, generate breathing cues. Returns (modified_text, hints).
    - `_inject_clause_commas(self, text: str) -> str` -- uses _LONG_UNPUNCTUATED.sub with callback. Callback checks word count >= threshold, tries _COORD_CONJ first (need 3+ words each side), then _SUBORD_CONJ (need 4+ words before, 3+ after). Only first match per span. Runs _DOUBLE_PUNCT cleanup after.
    - `_insert_slow_tags(self, text: str) -> str` -- splits text at sentence boundaries. For each sentence, if it starts with an emotion tag (detected by _EMOTION_TAG.match), prepend [slow] before the emotion tag. Skip if [slow] already present. Rejoin sentences.
    - `_generate_pause_hints(self, text: str) -> list[PauseHint]` -- scan text for punctuation using _PUNCT_POSITIONS.finditer. For each match, look up base duration and source, apply _jittered_duration, create PauseHint.
    - `_jittered_duration(self, base_ms: float) -> float` -- `random.gauss(base_ms, base_ms * self._config.pause_jitter_pct)` clamped to [0.5*base, 1.5*base].
    - `_generate_breathing_cues(self, text: str) -> list[BreathingCue]` -- split at sentence boundaries. For sentences with 15+ words, add BreathingCue at sentence start position with probability based on word count (e.g., 0.3 for 15-20 words, 0.6 for 20-30, 0.9 for 30+).

    **Import `random` for jitter.** Use `import random` at top level. Do NOT import numpy -- stdlib only per RESEARCH.md.

    **Do NOT import from inference.py** -- redefine _EMOTION_TAG locally to avoid circular imports. The pattern is identical.
