Create `tools/tts_baseline/test_tags.py` that tests each inline tag by generating paired recordings (with tag vs without tag on the same base text).

**Tags to test** (4 tags, each with a carrier sentence designed to reveal the tag's effect):

1. **[pause]**: 
   - With: "I need to tell you something. [pause] It's about what happened yesterday."
   - Without: "I need to tell you something. It's about what happened yesterday."
   - Measurement: Compare total audio duration (pause should add ~400-800ms)

2. **[inhale]**:
   - With: "[inhale] Ladies and gentlemen, I want to thank each and every one of you for being here tonight on this special occasion."
   - Without: "Ladies and gentlemen, I want to thank each and every one of you for being here tonight on this special occasion."
   - Measurement: Check first 500ms of audio for breath-like energy (non-silent audio before speech onset)

3. **[slow]**:
   - With: "The results are in and [slow] I regret to inform you that the project has been cancelled."
   - Without: "The results are in and I regret to inform you that the project has been cancelled."
   - Measurement: Compare total audio duration (slow section should be longer)

4. **[fast]**:
   - With: "So basically [fast] what happened was the server crashed and we lost everything and nobody knew what to do [fast] but then Sarah fixed it."
   - Without: "So basically what happened was the server crashed and we lost everything and nobody knew what to do but then Sarah fixed it."
   - Measurement: Compare total audio duration (fast sections should make it shorter)

**Also test combination**: "[inhale] I have an announcement. [pause] [slow] We are shutting down the program effective immediately."

**Script structure:**
1. Define tag test cases as a list of dicts: `{"tag": "pause", "with_text": "...", "without_text": "...", "metric": "duration_diff"}`
2. For each test case, generate both versions using the same API pattern as test_subchunk.py:
   - URL: `http://127.0.0.1:8080/v1/tts`
   - Payload (msgpack): `{"text": text, "reference_id": "archie", "format": "wav", "temperature": 0.7, "top_p": 0.8, "repetition_penalty": 1.2, "max_new_tokens": 1024, "chunk_length": 200, "streaming": True}`
   - Headers: `{"Content-Type": "application/msgpack", "Accept": "audio/wav"}`
3. **Generate each pair 3 times** (to account for model stochasticity) and report median values
4. Save WAVs to `/home/prana/tts-test/outputs/tag_tests/{tag}_with_run{N}.wav` and `{tag}_without_run{N}.wav`
5. Measure per pair:
   - `duration_with` and `duration_without` (seconds)
   - `duration_diff_pct` = (with - without) / without * 100
   - `rms_first_500ms` for [inhale] test (detect breath energy)
6. Apply pass/fail criteria:
   - [pause]: PASS if median duration_diff > 200ms
   - [inhale]: PASS if median rms of first 500ms is > 1.5x the without version
   - [slow]: PASS if median duration_with > 1.05x duration_without (5% longer)
   - [fast]: PASS if median duration_with < 0.95x duration_without (5% shorter)
7. Save results to `/home/prana/tts-test/outputs/tag_tests/tag_results.json`

Then run the script: `python tools/tts_baseline/test_tags.py`
