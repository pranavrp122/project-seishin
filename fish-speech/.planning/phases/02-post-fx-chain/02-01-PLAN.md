    **PostFXConfig dataclass** (per CONTEXT.md decision #4, WARM-08):
    ```python
    @dataclass
    class PostFXConfig:
        eq_low_intensity: float = 1.0     # WARM-01: 0.0=flat, 1.0=+3dB at 250Hz
        eq_high_intensity: float = 1.0    # WARM-02: 0.0=flat, 1.0=+2dB at 8kHz
        compression_intensity: float = 1.0 # WARM-03: 0.0=1:1, 1.0=2:1 ratio
        deess_intensity: float = 1.0      # WARM-04: 0.0=flat, 1.0=-6dB at 6.5kHz
        saturation_intensity: float = 1.0  # WARM-05: 0.0=clean, 1.0=full drive
    ```
    All fields are float, range [0.0, 1.0]. No limiter intensity (WARM-06 is always on).

    **HumanismPostFX class** (per CONTEXT.md decisions #3, #5, #6):
    - `__init__(self, config: PostFXConfig)`: Stores config, calls `_build_board()`, sets `self._first_call = True`
    - `_build_board(self, cfg: PostFXConfig) -> Pedalboard`: Builds chain in order: De-ess -> EQ low -> EQ high -> Compress -> Clipping. Skip plugins where intensity is 0.0.
      - De-ess (WARM-04): `PeakFilter(cutoff_frequency_hz=6500, gain_db=cfg.deess_intensity * -6.0, q=4.0)`
      - Low-shelf (WARM-01): `LowShelfFilter(cutoff_frequency_hz=250, gain_db=cfg.eq_low_intensity * 3.0, q=0.7)`
      - High-shelf (WARM-02): `HighShelfFilter(cutoff_frequency_hz=8000, gain_db=cfg.eq_high_intensity * 2.0, q=0.7)`
      - Compression (WARM-03): `Compressor(threshold_db=-20.0, ratio=1.0 + cfg.compression_intensity * 1.0, attack_ms=10.0, release_ms=100.0)`
      - Clipping (WARM-06): `Clipping(threshold_db=-0.1)` -- always added, no intensity knob
    - `process(self, audio: np.ndarray, sample_rate: int) -> np.ndarray`:
      1. Run `self._board.process(audio, sample_rate, reset=self._first_call)` -- reset=True on first call only, reset=False thereafter
      2. Set `self._first_call = False`
      3. If `self._config.saturation_intensity > 0`: apply `_apply_saturation()`
      4. Return `np.clip(result, -1.0, 1.0)` as final safety
    - `_apply_saturation(self, audio: np.ndarray, intensity: float) -> np.ndarray`:
      - `drive = 1.0 + intensity * 2.0` (range [1.0, 3.0])
      - `k = intensity * 0.1` (range [0.0, 0.1])
      - `driven = drive * audio`
      - `saturated = np.tanh(driven)`
      - `mask = audio < 0`
      - `saturated[mask] += k * audio[mask] ** 2`
      - Return `saturated`

    Use `Clipping(threshold_db=-0.1)` NOT `Limiter()` -- Limiter normalizes audio to [-1,1] even when input is quiet (pedalboard GitHub issue #282).
