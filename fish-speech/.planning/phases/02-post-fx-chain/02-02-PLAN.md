  <action>
    Modify `fish_speech/inference_engine/__init__.py` with these specific changes:

    **1. Update imports (top of file):**
    - REMOVE: `from pedalboard import Pedalboard, PeakFilter`
    - ADD: `from fish_speech.utils.post_fx import HumanismPostFX, PostFXConfig`

    **2. Remove class-level _post_fx (lines 25-27):**
    - DELETE the entire `_post_fx = Pedalboard([PeakFilter(...)])` class variable

    **3. Modify `get_audio_segment()` (line 261-279):**
    - REMOVE the `return self._post_fx(audio, sr)` at line 279
    - REPLACE with `return audio` -- get_audio_segment now returns raw decoded audio
    - This separates decoding from FX, allowing per-request stateful FX

    **4. Add per-request HumanismPostFX in `inference()` method:**
    - After `crossfader = StreamingCrossfader(...)` (line 90), add:
      ```python
      post_fx = HumanismPostFX(PostFXConfig())
      ```
    - This creates a fresh instance per inference request (WARM-07: no state leakage).

    **5. Apply post_fx.process() to every audio segment before yield:**
    There are 5 places where audio segments are yielded. Apply `post_fx.process(audio, sample_rate)` at each:

    a. **Sub-chunk partial streaming** (around line 123-147, `result.is_partial` block):
       After `segment = self.get_audio_segment(result)` and extracting `new_audio = segment[prev_audio_samples:]`:
       - Apply FX to the full decoded segment BEFORE slicing: `segment = post_fx.process(segment, sample_rate)` right after `segment = self.get_audio_segment(result)` on line 123
       - This ensures the compressor sees the full context, not just the new portion

    b. **Final chunk of sub-chunk mode** (around line 152, `is_sub_chunk_mode` block after `is_partial=False`):
       - Same pattern: `segment = post_fx.process(self.get_audio_segment(result), sample_rate)` on line 152

    c. **Non-sub-chunk crossfader path** (around line 173, else block):
       - `segment = post_fx.process(self.get_audio_segment(result), sample_rate)` replacing line 173

    d. **Flush sub-chunk tail** (around line 185):
       - `prev_batch_tail` is already processed audio, no additional FX needed here

    e. **Crossfader flush** (around line 195):
       - `tail` from crossfader is already-processed audio, no additional FX needed

    **Key principle:** Apply `post_fx.process()` immediately after `get_audio_segment()` and BEFORE any crossfade/slice operations. The compressor/EQ state is maintained across calls via `reset=False` (handled internally by HumanismPostFX).

    **Do NOT:**
    - Put post_fx back inside `get_audio_segment()` -- it must be per-request, not class-level
    - Use `reset=True` on any call except the first (HumanismPostFX handles this internally)
    - Create a shared/class-level HumanismPostFX instance (concurrent request state corruption, per Pitfall 3)
  </action>
