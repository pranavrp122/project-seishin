  <action>
Create `tools/tts_baseline/generate_corpus.py` that:

1. **Loads prompts** from `tools/tts_baseline/prompts.json`
2. **Accepts CLI args**: `--corpus baseline|adversarial|all` (default: all), `--output-dir PATH`
3. **For each prompt**, calls the Fish Speech API using the same pattern as test_subchunk.py:
   - URL: `http://127.0.0.1:8080/v1/tts`
   - Payload (msgpack): `{"text": prompt_text, "reference_id": "archie", "format": "wav", "temperature": 0.7, "top_p": 0.8, "repetition_penalty": 1.2, "max_new_tokens": 1024, "chunk_length": 200, "streaming": True}`
   - Headers: `{"Content-Type": "application/msgpack", "Accept": "audio/wav"}`
   - Stream response, extract PCM after 44-byte WAV header
   - Convert int16 PCM to float32 via `np.frombuffer(pcm, dtype=np.int16).astype(np.float32) / 32768.0`
   - Write via `sf.write(path, samples, 44100, format="wav")`
4. **Output structure**:
   - Baseline: `/home/prana/tts-test/outputs/baseline_corpus/{id}_{category}.wav`
   - Adversarial: `/home/prana/tts-test/outputs/adversarial_corpus/{id}_{category}.wav`
5. **Logs per clip**: TTFA (ms), total generation time (s), audio duration (s), file path
6. **Saves metadata**: `corpus_metadata.json` in each output dir with per-clip stats (duration_s, ttfa_ms, total_s, sample_rate, num_samples)
7. **Error handling**: If API returns non-200, log error and continue to next prompt (don't abort)

Then run: `python tools/tts_baseline/generate_corpus.py --corpus all`

This produces both corpora in a single script run. The script is reusable for re-generating after pipeline changes in later phases.
  </action>
